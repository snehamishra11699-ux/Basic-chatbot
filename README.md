# Basic Chatbot

## Description
This is a simple Basic Chatbot developed in Python as part of the CodeAlpha Python Programming Internship.

The chatbot interacts with users by responding to predefined questions and greetings through a console-based interface.

## Features
- Greets the user
- Responds to basic questions
- Simple text-based conversation
- Easy to understand and modify

## Technologies Used
- Python 3

## Project Files
- basic.py - Main chatbot program

## How to Run

1. Install Python 3 on your computer.
2. Open the project folder.
3. Run the following command:

```bash
python basic.py
```

## Sample Conversation

```
User: Hello
Bot: Hi! How can I help you?

User: What is your name?
Bot: I am a Basic Python Chatbot.

User: Bye
Bot: Goodbye! Have a nice day.
```
